Hướng dẫn sử dụng

Chạm vào từng mục để xem cách làm.

1Xuất file Excel gửi VNPost
  1. Chọn Tab tháng cần xuất (ví dụ DS T10).
  2. Chọn Lấy đơn từ file: DS Lẻ, DS CTV hoặc Cả 2 file (DS Lẻ đứng trước, STT đánh liên tục).
  3. Chọn Mẫu file Excel: HANH_NGUYEN hoặc AN MAITRI.
  4. Bấm nút vàng Xuất file Excel. Xong sẽ hiện tên file, nút Mở trong Drive, Tải về và Gửi Zalo.

App chỉ lấy dòng có cân nặng ở cột M và đang hiển thị theo bộ lọc của sheet.

  • Cân nặng dạng 2+3 được tách thành 2 dòng, tên thêm 1/2, 2/2. COD chỉ giữ ở dòng đầu. Các dòng sau: mẫu HANH_NGUYEN, AN MAITRI ghi 5 nếu khách chịu phí ship, còn lại ghi 0; mẫu VIETTEL luôn ghi 0 K.
  • Cột ghi chú chỉ giữ nội dung có "ship nhanh" hoặc "không thu tiền".
  • Tên, SĐT, địa chỉ bị trùng được tô màu cam để kiểm tra.
  • Đơn từ 4kg trở lên (từ 4.000g): ô khối lượng ở cột I và cột AN tô nền tím.
  • Đơn từ 4kg trở lên gửi miền Trung, miền Nam (từ Đà Nẵng trở vào): cột ghi chú tự ghi SHIP NHANH.
  • Mẫu HANH_NGUYEN và AN MAITRI: mỗi tháng 1 file Excel trong thư mục Output (ví dụ T10.2026.HANH_NGUYEN_Vnpost.xlsx). Mỗi lần xuất thêm 1 tab tên ngày (14.10) ở đầu file; xuất lần 2 trong ngày tạo tab 14.10 (2). Đầu tháng app tự tạo file mới.
  • Mẫu "Theo cột Q": bấm Xuất 1 lần, app tự chia đơn có cân nặng theo cột Q (SHIP): ô trống → HANH_NGUYEN, AMT → AN MAITRI, VIETTEL → Viettel post - PAH. Đơn vị nào không có đơn thì bỏ qua.
  • Mẫu VIETTEL: thêm tab ngày vào file Google Sheet "Viettel post - PAH", giữ nguyên dòng tổng ở cuối. Tab mới tự lọc chỉ hiện dòng có khách, dòng trống được ẩn (bấm biểu tượng lọc ở cột C để hiện lại).
2Xuất PDF danh sách khách hàng

Chọn tab và file như khi xuất Excel, rồi bấm Xuất PDF. File PDF gồm các dòng đang hiển thị, từ cột A đến cột N.

Chọn Đơn vị vận chuyển (VNPOST, VIETTEL, AMT) để chỉ in đơn của đơn vị đó theo cột Q (SHIP): ô trống là VNPOST. Không cần lọc tay cột Q trên sheet nữa. Cột STT trong PDF được đánh lại 1, 2, 3… riêng cho DS Lẻ và DS CTV. Dòng TỔNG CỘNG tự tính lại Thu COD theo đơn vị đã chọn. Tên file có ngày giờ ở đầu và đơn vị ở cuối, ví dụ 19.10.2026_0815_DS_khach_hang_GOP_VNPOST.pdf.

Đơn nào có chữ ưu tiên ở cột Ghi chú thì chân mọi trang của danh sách đó (Lẻ hoặc CTV) tự có dòng ƯU TIÊN ĐƠN SỐ : …, liệt kê đủ số STT các đơn ưu tiên.

3Ô "Đơn sẵn sàng xuất" và mở file nguồn

Cho biết số đơn có cân nặng và đang hiển thị ở từng file. Sau khi nhập thêm cân nặng, bấm nút làm mới (mũi tên tròn) để đếm lại.

Chạm vào thẻ DS Lẻ hoặc DS CTV để mở thẳng file Google Sheet, đúng tab tháng đang chọn.

4Nhập cân nặng và tự ghi trạng thái

Nhập tay trên sheet: gõ cân nặng vào cột M. Cột O tự ghi "đã trả hàng", cột P tự ghi ngày hôm nay. Xóa cân nặng ở cột M thì cột O tự về 1.

Nhập từ ảnh: gửi ảnh danh sách viết tay vào Claude Project, kiểm tra bảng Claude đề xuất rồi xác nhận để ghi.

Ô "Nhập cân nặng" trên app chỉ hiện khi đã cài khóa API Claude. Nếu còn sót dòng chưa ghi "đã trả hàng", dùng menu Xuất Excel → Ghi "đã trả hàng" cho các dòng đã có cân nặng.

5Gửi file qua Zalo hoặc Telegram

Bấm ô Gửi file (hoặc nút gửi ngay sau khi xuất), chạm chọn file, rồi chọn Gửi qua: Zalo hoặc Telegram.

Zalo: đợi file hiện "Sẵn sàng", bấm Gửi. Một tab mới mở ra, bấm Chọn Zalo để gửi, chọn người nhận hoặc nhóm.

Điện thoại Android thường không cho gửi thẳng file Excel qua Zalo. Khi đó dùng Telegram, hoặc bấm Mở Drive → ⋮ → Gửi bản sao → Zalo.

Telegram: chọn người nhận, bấm Gửi. Bot gửi thẳng file (cả Excel và PDF), không cần mở thêm tab.

Cài Telegram lần đầu (trên máy tính):

  1. Trong Telegram, tìm @BotFather, gửi lệnh /newbot, đặt tên bot và tên đăng nhập (kết thúc bằng "bot"). BotFather trả về một token.
  2. Trong Apps Script: Cài đặt dự án → Thuộc tính tập lệnh → thêm TELEGRAM_BOT_TOKEN, giá trị là token vừa nhận → Lưu.
  3. Người nhận tìm bot của bạn trong Telegram và bấm Start. Với nhóm: thêm bot vào nhóm rồi nhắn 1 tin trong nhóm.
  4. Trên app: Gửi file → Telegram → + Thêm người nhận → Tìm người nhận mới → bấm Thêm.

Giữ token bot bí mật. Ai có token đều điều khiển được bot.

6Nối PDF, gộp Excel

Nối PDF: bấm ô Nối PDF, chạm vào các file theo đúng thứ tự muốn ghép (số trong vòng tròn là thứ tự), có thể thêm PDF từ điện thoại, rồi bấm Nối file.

Gộp Excel: bấm ô Gộp Excel, chọn các file theo thứ tự. Đơn của file số 1 đứng đầu, STT đánh lại liên tục. Các file phải cùng mẫu cột.

7Đổi tên file, mở thư mục Output

Ở mục Đã xuất gần đây, bấm Đổi tên cạnh file, nhập tên mới rồi Lưu tên (đuôi .xlsx / .pdf giữ nguyên).

Nút Output trên cùng mở thư mục chứa mọi file đã xuất trên Google Drive.

8Dùng trên máy tính

Cách 1: mở đúng link app này bằng trình duyệt trên máy tính (đăng nhập cùng tài khoản Google). Nên lưu link vào dấu trang.

Cách 2: mở file Google Sheet chứa code của app, vào menu Xuất Excel → Mở bảng xuất đơn. Bảng hiện ngay trong sheet, đủ chức năng như trên điện thoại.

9Sang tháng mới

Chỉ cần đổi tên tab theo tháng, ví dụ DS T10 → DS T11. Tên tab phải bắt đầu đúng "DS T" (có dấu cách sau DS).

Không dùng "Tạo bản sao" để làm file tháng mới, vì bản sao có ID khác và app sẽ vẫn đọc file cũ. Giữ nguyên dòng tiêu đề và thứ tự cột.

10Khi gặp sự cố
  • "Đang có một lần xuất khác chạy": đợi vài phút rồi bấm lại.
  • Số đơn hiện "–": bấm nút làm mới; nếu vẫn vậy, đóng app và mở lại.
  • Không thấy tab tháng mới: kiểm tra tên tab có bắt đầu bằng "DS T" không, rồi tải lại app.
  • Thiếu đơn khi xuất: kiểm tra dòng đó đã có cân nặng ở cột M và không bị bộ lọc ẩn.
